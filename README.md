# Actor List CR Badges

A Foundry VTT module for the D&D 5e system that shows each creature's Challenge Rating (CR) as a badge in the Actor Directory, and can sort the directory by CR.

> **Note:** This module was generated by Claude, Anthropic's AI assistant, using Claude Code.

## Features

- **CR badges:** NPC actors show a `CR` badge in the Actors sidebar. Fractional CRs show as `1/8`, `1/4` and `1/2`.
- **Sort by CR:** a **CR** button in the Actors sidebar header sorts actors from lowest to highest CR.
  - Actors with the same CR are listed alphabetically.
  - Actors without a CR, such as player characters, are listed last, alphabetically.
  - Sorting happens inside each folder. Folders themselves don't move.
  - The setting is saved per user. Click the button again to return to Foundry's normal order.

## Compatibility

- Foundry VTT v12 to v14
- D&D 5e system

## Installation

Copy this folder into your Foundry `Data/modules/` directory as `actor-list-cr`, then enable **Actor List CR Badges** in your world's module settings.
